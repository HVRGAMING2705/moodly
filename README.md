# Moodly - Mood Tracker App

A fully functional mood tracker with daily entries, mood history, and visual statistics. No login or registration required.

## Features

- daily entries
- mood history
- visual statistics

## Modules

- `moodly_mood_tracker_app`: daily_entries, mood_history, visual_statistics

## Tech Stack
